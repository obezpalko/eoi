# 046: Las estaciones y el tiempo

## Información
### Próximos Exámenes (Mayo)

## El Tiempo y las Estaciones
### Las estaciones del año
- **Primavera**: las flores.
- **Verano**: la playa.
- **Otoño**: la lluvia y el viento.
- **Invierno**: el frío, la nieve y el viento.
	- *En Dénia no nieva nunca, ni siquiera en invierno.*

### El tiempo atmosférico
| Condición   | Expresiones y Verbos       | Gerundio (Ahora)                  |
| :---------- | :------------------------- | :-------------------------------- |
| ☀️ Sol      | Hace sol                   | Está **soleado** / Está despejado |
| 🥵 Calor    | Hace calor                 | -                                 |
| ❄️ Frío     | Hace frío                  | -                                 |
| 🌬️ Viento  | Hace viento / Hay viento   | -                                 |
| ☁️ Nubes    | Hay nubes                  | Está **nublado**                  |
| 🌫️ Niebla  | Hay niebla                 | -                                 |
| ⛈️ Tormenta | Hay tormenta / Hay rayos   | -                                 |
| 🌧️ Lluvia  | **Llueve** (Llover, o->ue) | Está **lloviendo**                |
| ❄️ Nieve    | **Nieva** (Nevar, e->ie)   | Está **nevando**                  |
| 🧊 Granizo  | **Graniza** (Granizar)     | Está granizando                   |

### Vocabulario específico
- **El chirimiri**: Lluvia muy fina.
- **Chispear**: Empezar a llover (caer gotas sueltas).
- **Las gotas**: Drops.

## Gramática
### Pretérito Indefinido (Pasado)
Terminaciones para verbos regulares acabados en **-er** e **-ir**:

| Persona          | nacer / beber       |
| :--------------- | :------------------ |
| Yo               | nac**í** / beb**í** |
| Tú               | nac**iste**         |
| Él/Ella/Ud.      | nac**ió**           |
| Nosotros         | nac**imos**         |
| Vosotros         | nac**isteis**       |
| Ellos/Ellas/Uds. | nac**ieron**        |

### Apócope del adjetivo
Cuando el adjetivo va delante del sustantivo, a veces se acorta:
- **Bueno** -> **Buen**: *Un buen tiempo* (frente a *Un tiempo bueno*).
- **Grande** -> **Gran**: *Un gran día* (calidad) frente a *Un día grande* (tamaño).

## Vocabulario de la lección
- **vestir**: to dress / одевать.
- **el equinoccio**: equinox / равноденствие.
- **el solsticio**: solstice / солнцестояние.
- **nacer**: to be born / рождаться.
- **la ciudad ventosa**: windy city / ветреный город.
- **la sombrilla**: beach umbrella / зонтик (от солнца).
- **transparente**: transparent / прозрачный.
- **lila**: lilac / лиловый.
