# 049: El Tiempo Atmosférico y Verbos Impersonales

[[../40-Deberes/20260427 Lección cuarenta y nueve|📝 Deberes de la lección]]

## 🌤️ El Tiempo Atmosférico

En español usamos tres verbos principales para hablar del clima: **Hacer**, **Estar** y **Haber**, además de los verbos específicos de fenómenos.

### Estructuras Principales

| Verbo | Uso | Ejemplo |
| :--- | :--- | :--- |
| **HACE** + Sustantivo | Sensación general | **Hace** sol, **hace** frío, **hace** viento. |
| **ESTÁ** + Adjetivo/Gerundio | Estado actual | **Está** nublado, **está** lloviendo. |
| **HAY** + Sustantivo | Existencia de algo | **Hay** niebla, **hay** tormenta, **hay** humedad. |

### Efectos: Verbos vs. Sustantivos

| Efecto | Verbo (Acción) | Sustantivo (El fenómeno) | Traducción |
| :--- | :--- | :--- | :--- |
| **Lluvia** | **Llover** (llueve) | La lluvia | Rain / Дождь |
| **Nieve** | **Nevar** (nieva) | La nieve | Snow / Снег |
| **Viento** | **Soplar** (sopla) | El viento | Wind / Ветер |
| **Sol** | **Brillar** (brilla) | El sol | Sun / Солнце |
| **Trueno** | **Tronar** (truena) | El trueno | Thunder / Гром |
| **Rayo** | **Relampaguear** | El rayo / El relámpago | Lightning / Молния |
| **Granizo** | **Granizar** | El granizo | Hail / Град |

### La Temperatura

* **Hace calor:** It is hot / Жарко.
* **Hace frío:** It is cold / Холодно.
* **Hace fresco:** It is cool/chilly / Прохладно.
* **Estamos a...** (Para grados específicos): "En Dénia **estamos a** 22 grados".

## ☁️ Verbos Impersonales

Los verbos impersonales solo se conjugan en la **3ª persona del singular** (él/ella/ello). No tienen un sujeto humano.

### Fenómenos de la Naturaleza

| Verbo | Español (3ª pers.) | Traducción |
| :--- | :--- | :--- |
| **Llover (o > ue)** | **Llueve** | It rains / Идет дождь |
| **Nevar (e > ie)** | **Nieva** | It snows / Идет снег |
| **Granizar** | **Graniza** | It hails / Идет град |
| **Tronar (o > ue)** | **Truena** | It thunders / Гремят раскаты грома |
| **Relampaguear** | **Relampaguea** | It flashes / Сверкает молния |
| **Diluviar** | **Diluvia** | It pours / Льет как из ведра |
| **Chispear** | **Chispea** | It drizzles / Моросит |
| **Amanecer** | **Amanece** | It dawns / Светает |
| **Atardecer** | **Atardece** | It gets dark / Смеркается |
| **Anochecer** | **Anochecer** | Night falls / Наступает ночь |

### Otros Verbos Impersonales Populares

| Verbo | Uso Impersonal | Traducción |
| :--- | :--- | :--- |
| **Haber** | **Hay** | There is / There are |
| **Basta** | **Basta con...** | It is enough... |
| **Sobrar** | **Sobra con...** | It is more than enough |
| **Parecer** | **Parece que...** | It seems that... |
| **Importar** | **No importa** | It doesn't matter |
| **Convenir** | **Conviene...** | It is advisable... |
| **Suceder** | **Sucede que...** | It happens that... |
| **Tratarse** | **Se trata de...** | It is about... |

## 💡 Reglas Importantes (Nivel A2)

1. **El verbo HABER:** En su forma impersonal (**Hay**), nunca se usa en plural para objetos. 
   * *Correcto:* Hay muchas personas. 
   * *Incorrecto:* Han muchas personas.
2. **Hacer:** Se usa para la temperatura y el tiempo.
   * "Hace calor", "Hace viento", "Hace buen tiempo".
3. **Gerundio:** Para decir que está ocurriendo ahora:
   * "Está lloviendo", "Está nevando".

## 📝 Prácticas (Ejemplos)

1. **Clima:** "Hoy en Dénia **hace** muy buen tiempo, no **llueve** nada."
2. **Mañana:** "**Amanece** muy pronto en verano, sobre las seis."
3. **Existencia:** "En el puerto **hay** muchos barcos de pesca."
4. **Opinión:** "**Parece que** mañana va a hacer viento en el Montgó."
