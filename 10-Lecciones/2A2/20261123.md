## 📖 Glosario Trilingüe (ES / EN / RU)

### 1. Forma de la cara
- **Cara redonda:** *Round face* / Круглое лицо
- **Cara cuadrada:** *Square face* / Квадратное лицо
- **Cara ovalada:** *Oval face* / Овальное лицо
- **Cara fina:** *Thin / narrow face* / Узкое (худое) лицо
- **Cara pequeña / ancha:** *Small / wide face* / Маленькое / широкое лицо

### 2. Ojos
- **Ojos saltones:** *Bulging / protruding eyes* / Глаза навыкате
- **Ojos separados / juntos:** *Wide-set / close-set eyes* / Широко / близко посаженные глаза
- **Ojos cansados:** *Tired eyes* / Уставшие глаза
- **Ojos pequeños:** *Small eyes* / Маленькие глаза
- **Ojos miopes:** *Nearsighted / squinting eyes* / Близорукие глаза

### 3. Nariz
- **Nariz aguileña:** *Aquiline / hooked nose* / Орлиный нос (с горбинкой)
- **Nariz chata:** *Flat / snub nose* / Курносый (приплюснутый) нос
- **Nariz con piercing:** *Nose with a piercing* / Нос с пирсингом
- **Nariz ancha:** *Wide nose* / Широкий нос
- **Nariz puntiaguda:** *Pointy nose* / Острый нос
- **Nariz torcida:** *Crooked nose* / Кривой нос

### 4. Boca
- **Boca enorme / diminuta:** *Huge / tiny mouth* / Огромный / крошечный рот
- **Boca carnosa:** *Full / fleshy lips (mouth)* / Пухлые губы
- **Boca fina:** *Thin lips (mouth)* / Тонкие губы
- **Boca torcida:** *Crooked mouth* / Кривой рот
- **Boca maquillada:** *Made-up mouth (with lipstick)* / Накрашенный рот

### 5. Orejas
- **Orejas diminutas / grandes:** *Tiny / big ears* / Крошечные / большие уши
- **Orejas de soplillo:** *Sticking-out / jug ears* / Оттопыренные уши
- **Orejas asimétricas:** *Asymmetrical ears* / Асимметричные уши
- **Orejas puntiagudas:** *Pointy ears* / Острые уши
- **Orejas perforadas:** *Pierced ears* / Проколотые уши

### 6. Pelo
- **Pelo rapado:** *Shaved / buzzed head* / Бритый налысо (под машинку)
- **Pelo encrespado:** *Frizzy hair* / Пушащиеся (взлохмаченные) волосы
- **Pelo con cresta:** *Mohawk / spiky hair* / Волосы с ирокезом
- **Pelo rizado:** *Curly hair* / Кудрявые волосы
- **Pelo trenzado:** *Braided hair* / Заплетённые в косы волосы
- **Pelo repeinado:** *Slicked-back hair* / Гладко причёсанные (прилизанные) волосы

### 7. Piel
- **Piel con arrugas:** *Wrinkly skin* / Морщинистая кожа
- **Piel con acné:** *Acne-prone skin* / Кожа с акне (прыщами)
- **Piel tatuada:** *Tattooed skin* / Татуированная кожа
- **Piel flácida:** *Saggy / flabby skin* / Дряблая кожа
- **Piel maquillada:** *Made-up skin (with makeup)* / Кожа с макияжем
- **Piel con cicatrices:** *Scarred skin* / Кожа со шрамами
