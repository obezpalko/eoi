# 📝 Evaluación: Unidades 7, 8 y 9
![[attachments/test3.jpg]]

## Test de Gramática y Vocabulario

- [x] **1. ¿La sopa del día ............ qué es?**
  - **Respuesta:** **b. de**
  - **Explicación:** La preposición **de** se utiliza para preguntar o especificar la materia o el ingrediente principal de un plato (*sopa de...*).

- [x] **2. • Por favor, ¿me ............ otro café?**  
  **◦ Ahora mismo.**
  - **Respuesta:** **b. pone**
  - **Explicación:** Es la fórmula habitual y de cortesía empleada en bares y restaurantes para pedir una consumición (*¿Me pone...?*).

- [x] **3. • El café ¿............ tomas solo o con leche?**  
  **◦ Con leche.**
  - **Respuesta:** **b. lo**
  - **Explicación:** Sustituye al objeto directo masculino singular (*el café*) mediante el pronombre **lo**.

- [x] **4. ¿Qué hay normalmente en la carta de un restaurante español?**
  - **Respuesta:** **c. Primeros, segundos y postres.**
  - **Explicación:** Estructura tradicional del menú español: primeros platos, segundos platos y postres.

- [x] **5. Las patatas que acompañan el pescado, ¿cómo ............ prefiere, fritas o cocidas?**
  - **Respuesta:** **a. las**
  - **Explicación:** Pronombre de objeto directo femenino plural que concuerda con el sustantivo *las patatas*.

- [x] **6. • ............**  
  **◦ Son 20,50.**
  - **Respuesta:** **b. ¿Qué le pongo?**
  - **Explicación:** Pregunta característica que utiliza el vendedor o camarero para ofrecer atención o pedir la comanda.

- [x] **7. • Perdone, ¿está muy lejos la parada de metro?**  
  **◦ No, está a unos 5 minutos ............**
  - **Respuesta:** **a. a pie**
  - **Explicación:** La locución exacta para indicar desplazamiento caminando es **a pie**.

- [x] **8. • Por aquí hay una plaza muy famosa, ¿no?**  
  **◦ Sí, hay varias. ............ más conocida es la del 2 de mayo.**
  - **Respuesta:** **c. La**
  - **Explicación:** El superlativo relativo de un sustantivo femenino omitido (*plaza*) se forma con el artículo femenino **La** (*La más conocida*).

- [x] **9. • ¿Dónde está la farmacia?**  
  **◦ En la ............**
  - **Respuesta:** **c. esquina**
  - **Explicación:** *En la esquina* es la localización espacial adecuada para indicar la intersección de dos calles.

- [x] **10. Tengo ganas de ir a un restaurante tailandés. ¿Conoces ............?**
  - **Respuesta:** **b. alguno**
  - **Explicación:** Funciona como pronombre indefinido masculino singular. Al no ir seguido inmediatamente por el sustantivo, se usa la forma completa *alguno*.

- [x] **11. Las calles de mi barrio son bastante ............**
  - **Respuesta:** **c. anchas**
  - **Explicación:** Adjetivo en femenino plural para concordar con el sujeto *las calles*.

- [x] **12. ¿Hay algún parque cerca de tu casa?**
  - **Respuesta:** **a. No, no hay ninguno.**
  - **Explicación:** La respuesta negativa completa exige la estructura de doble negación **No + verbo + ninguno**.

- [x] **13. Una zona de una ciudad por donde no pueden circular coches se llama ............**
  - **Respuesta:** **c. zona peatonal**
  - **Explicación:** Definición urbanística de un área reservada exclusivamente para los peatones.

- [x] **14. El jamón es...**
  - **Respuesta:** **a. un embutido.**
  - **Explicación:** Clasificación gastronómica correspondiente a los productos cárnicos curados.

- [x] **15. • Edith, ¿tú qué ............?**  
  **◦ Economía.**
  - **Respuesta:** **b. has estudiado**
  - **Explicación:** La segunda persona del singular (*tú*) en Pretérito Perfecto Compuesto se forma con el auxiliar **has + participio**.

- [x] **16. ¿Para beber?**
  - **Respuesta:** **c. Un vaso de vino tinto.**
  - **Explicación:** Es la única opción que representa una bebida. La sopa y el gazpacho se consideran alimentos líquidos/platos.

- [x] **17. Las verduras las como siempre...**
  - **Respuesta:** **b. cocidas.**
  - **Explicación:** El participio con función adjetiva concuerda en femenino plural con *las verduras*.

- [x] **18. En mi barrio hay ............ ambiente.**
  - **Respuesta:** **c. poco**
  - **Explicación:** El cuantificador concuerda en masculino singular con el sustantivo no contable *ambiente*.

- [x] **19. • ¿............ dibujar?**  
  **◦ Sí, pero ahora no ............ Me he roto el brazo.**
  - **Respuesta:** **c. Sabes / puedo**
  - **Explicación:** Se utiliza **saber** para expresar capacidad o habilidad adquirida (*¿Sabes dibujar?*), y **poder** para indicar la posibilidad física puntual (*ahora no puedo [porque me he roto el brazo]*).

- [x] **20. • ¿Has ido ............ vez a China?**  
  **◦ Sí, ............ vez.**
  - **Respuesta:** **a. alguna / una**
  - **Explicación:** La expresión *alguna vez* pregunta por la experiencia en general, y la respuesta cuantifica la frecuencia exacta (*una vez*).
