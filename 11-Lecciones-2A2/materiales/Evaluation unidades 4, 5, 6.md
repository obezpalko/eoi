## Test de Gramática y Vocabulario

- [x] **1. • ¿Vamos mañana al cine?**  
  **◦ No puedo, ............ trabajar.**
  - **Respuesta:** **c. tengo que**
  - **Explicación:** Se usa la estructura obligatoria **tener que + infinitivo**. Para la primera persona (*yo*), el verbo conjugado es *tengo*.

- [x] **2. ¿Qué compra esta persona?: «Me llevo las marrones.»**
  - **Respuesta:** **b. Unas sandalias**
  - **Explicación:** El artículo y el adjetivo (*las marrones*) están en femenino plural. El único sustantivo femenino plural de las opciones es *sandalias*.

- [x] **3. ¿Con qué te lavas los dientes?**
  - **Respuesta:** **c. Con pasta de dientes.**
  - **Explicación:** Es el producto específico utilizado para la higiene bucal. *Cepillo del pelo* es para el cabello y *gel de baño* para el cuerpo.

- [x] **4. ¿Cuánto ............ estos zapatos?**
  - **Respuesta:** **c. cuestan**
  - **Explicación:** El sujeto (*estos zapatos*) es plural (*ellos*). El verbo *costar* cambia la raíz a *-ue-* en tercera persona de plural: *cuestan*.

- [x] **5. De las dos faldas, ............**
  - **Respuesta:** **a. ¿cuál te gusta más?**
  - **Explicación:** Cuando se elige dentro de un grupo limitado (*las dos faldas*), se utiliza el interrogativo **cuál**. Al referirse a una sola falda de las dos, el verbo va en singular (*gusta*).

- [x] **6. ............ zapatos son muy bonitos, ¿no?**
  - **Respuesta:** **b. Estos**
  - **Explicación:** Demostrativo masculino plural que concuerda con el sustantivo *zapatos*. La forma *estes* no existe en español.

- [x] **7. • Y tú, ............**  
  **◦ Pues, bueno, me gusta bastante la fotografía.**
  - **Respuesta:** **c. ¿qué aficiones tienes?**
  - **Explicación:** La respuesta habla de un pasatiempo o afición (*la fotografía*), por lo que la pregunta adecuada es sobre *aficiones*.

- [x] **8. Oye, ¡tu amigo Juanjo ............ simpático!**
  - **Respuesta:** **a. es un poco**
  - **Explicación:** Para describir el carácter o la personalidad de una persona de forma permanente se utiliza el verbo **ser**.

- [x] **9. A mi hermano ............ encanta leer.**
  - **Respuesta:** **a. le**
  - **Explicación:** Con verbos tipo *gustar* o *encantar*, el pronombre de objeto indirecto para la tercera persona del singular (*él / mi hermano*) es **le**.

- [x] **10. • Tu tío Juan, ¿es ............ de tu padre?**  
  **◦ No, de mi madre.**
  - **Respuesta:** **a. hermano**
  - **Explicación:** Pregunta por el parentesco directo respecto a la rama familiar (*hermano de tu padre / de tu madre*).

- [x] **11. ¿Cuál es tu ciudad ............?**
  - **Respuesta:** **b. preferida**
  - **Explicación:** El sustantivo *ciudad* es femenino singular, por lo que exige el adjetivo en femenino singular (*preferida*).

- [x] **12. • Me encantan las películas de David Lynch.**  
  **◦ ¿Ah sí? ............**
  - **Respuesta:** **b. A mí también.**
  - **Explicación:** Para mostrar acuerdo con una afirmación positiva construida con verbos de gusto (*me encantan*), se usa **A mí también**.

- [x] **13. ¿Cuál de estos verbos no tiene relación con la comida?**
  - **Respuesta:** **b. Madrugar.**
  - **Explicación:** *Madrugar* significa levantarse muy temprano. *Cenar* y *almorzar* son verbos referidos a las comidas del día.

- [x] **14. • Yo nunca leo revistas. No tengo tiempo.**  
  **◦ ............**
  - **Respuesta:** **b. Yo tampoco. Pero porque no me gustan.**
  - **Explicación:** Para mostrar acuerdo con una oración negativa (*nunca leo*), se emplea la fórmula **Yo tampoco**.

- [x] **15. • ¿A qué hora ............ de casa para ir a trabajar?**  
  **◦ A las 8:30 h más o menos, ¿por qué?**
  - **Respuesta:** **a. sales**
  - **Explicación:** El verbo *salir* rige la preposición *de* para indicar el origen del movimiento (*salir de casa*).

- [x] **16. • ¿Haces mucho deporte?**  
  **◦ No, no mucho, solo ............**
  - **Respuesta:** **b. una vez por semana**
  - **Explicación:** La expresión de frecuencia debe ser coherente con la respuesta negativa parcial (*no mucho*).

- [x] **17. ... los dientes después de desayunar.**  
  **◦ Pues yo no, yo ............ me lavo los dientes y ............ desayuno.**
  - **Respuesta:** **c. primero / luego**
  - **Explicación:** Se emplean marcadores temporales para indicar el orden cronológico de las acciones: *primero* (en primer lugar) y *luego* (después).

- [x] **18. Siempre hago la cama antes...**
  - **Respuesta:** **b. de desayunar.**
  - **Explicación:** Delante de un verbo en infinitivo, la locución adverbial de tiempo exige la preposición **de**: **antes de + infinitivo**.

- [x] **19. ¿Te gustan...**
  - **Respuesta:** **a. los conciertos de música clásica?**
  - **Explicación:** La forma verbal *gustan* está en plural, por lo que requiere un sujeto en plural (*los conciertos*).

- [x] **20. • ¿Qué hora es?**  
  **◦ ............**
  - **Respuesta:** **c. Las seis y media.**
  - **Explicación:** La hora en español se expresa con el artículo determinado femenino plural (*las*) seguido del número y la fracción temporal (*y media*).
