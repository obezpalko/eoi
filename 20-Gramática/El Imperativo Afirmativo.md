# El Imperativo Afirmativo (Affirmative Imperative)

El imperativo se usa para dar órdenes, instrucciones, consejos o hacer invitaciones. En español, el imperativo afirmativo tiene formas propias para cada persona.

---

## 1. Verbos Regulares (Formación)

| Persona | -AR (Comprar) | -ER (Comer) | -IR (Escribir) | Inglés | Ruso |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Tú** (informal) | compr**a** | com**e** | escrib**e** | Speak / Eat / Write | Говори / Ешь / Пиши |
| **Usted** (formal) | compr**e** | com**a** | escrib**a** | Speak / Eat / Write | Говорите / Ешьте / Пишите |
| **Vosotros** (plural inf.) | compr**ad** | com**ed** | escrib**id** | Speak / Eat / Write | Говорите / Ешьте / Пишите |
| **Ustedes** (plural form.) | compr**en** | com**an** | escrib**an** | Speak / Eat / Write | Говорите / Ешьте / Пишите |

> [!TIP] **El truco del "Vosotros"**
> Para formar el "vosotros", simplemente cambiamos la **-r** final del infinitivo por una **-d**.
> *Ejemplo:* `Hablar` → `Hablad`. (¡Siempre es regular!).

---

## 2. Los 8 Irregulares (Persona "Tú")

Estos verbos son esenciales para la vida diaria. Las formas para *Usted, Vosotros* y *Ustedes* siguen otras reglas (subjuntivo), pero para **Tú** son estas formas cortas:

| Infinitivo | Imperativo (Tú) | Inglés | Ruso | Ejemplo |
| :--- | :--- | :--- | :--- | :--- |
| **Decir** | **di** | Say / Tell | Скажи | *Di la verdad.* |
| **Hacer** | **haz** | Do / Make | Сделай | *Haz la cama.* |
| **Ir** | **ve** | Go | Иди | *Ve al supermercado.* |
| **Poner** | **pon** | Put / Place | Поставь | *Pon la mesa.* |
| **Salir** | **sal** | Exit / Leave | Выходи | *Sal ahora mismo.* |
| **Ser** | **sé** | Be | Будь | *Sé bueno.* |
| **Tener** | **ten** | Have / Hold | Возьми | *Ten el ticket.* |
| **Venir** | **ven** | Come | Приходи | *Ven aquí.* |

---

## 3. Imperativo con Pronombres (COD y Reflexivos)

Cuando usamos pronombres (me, te, lo, la, nos, os, los, las) con el imperativo afirmativo, el pronombre **siempre se une al final** del verbo, formando una sola palabra.

### Ejemplos con Objetos Directos (COD):
*   Hacer las tareas → **Hazlas.**
*   Comprar el pan → **Cómpralo.**
*   Abrir la puerta → **Ábrela.**
*   Llamar a mí → **Llámame.**

### Ejemplos con Verbos Reflexivos:
*   Levantarse → **Levántate.**
*   Sentarse → **Siéntate.**
*   Ducharse → **Dúchate.**

> [!WARNING] **Cuidado con las tildes**
> Al unir el pronombre, a menudo la palabra se convierte en esdrújula, por lo que necesita llevar tilde escrita (acento) para mantener la fuerza de voz original.
> *   Ejemplo: **Com**-pra + lo = **Cómpralo**.

## 4. Frases Prácticas y Comunes

*   **Toma** (Tomar) - *Take (Here you go) / Возьми.*
*   **Trae** (Traer) - *Bring / Принеси.*
*   **Pasa** (Pasar) - *Come in / Проходи.*
*   **Dime** (Decir + me) - *Tell me / Скажи мне.*
*   **Dame** (Dar + me) - *Give me / Дай мне.*
*   **Ponme un café** - *Give me a coffee (Typical in bars) / Сделайте мне кофе.*
