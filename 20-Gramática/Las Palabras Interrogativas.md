# ❓ Las Palabras Interrogativas

Para hacer preguntas en español, utilizamos palabras específicas llamadas "interrogativos". Todas estas palabras comparten algunas reglas fundamentales de ortografía y uso.

---

## 📏 Reglas Fundamentales

1. **Signos Dobles**: En español es obligatorio cerrar la pregunta con `?`, pero también abrirla con `¿`.
2. **La Tilde Obligatoria (Acento Diacrítico)**: Cuando funcionan como interrogativos o exclamativos, estas palabras **siempre llevan tilde**. Esto las diferencia de sus relativos (donde, cuando, que...).
3. **Preposiciones**: Si el verbo o el sentido de la frase requiere una preposición, esta se coloca siempre **delante** del interrogativo.
   - *¿**A** qué hora...? / ¿**De** dónde...? / ¿**Con** quién...?*

---

## 🛠️ Los Interrogativos en detalle

| Interrogativo | Uso | Ejemplo (ES) | Significado (EN/RU) |
| :--- | :--- | :--- | :--- |
| **¿Qué?** | Objetos, definiciones, acciones. | *¿**Qué** estudias?* | What? / Что? |
| **¿Quién / es?** | Personas (tiene forma plural). | *¿**Quién** es ella?* | Who? / Кто? |
| **¿Cuándo?** | Tiempo o momento. | *¿**Cuándo** vienes?* | When? / Когда? |
| **¿Dónde?** | Lugar o ubicación. | *¿**Dónde** vives?* | Where? / Где? |
| **¿Cómo?** | Modo, forma o estado. | *¿**Cómo** estás?* | How? / Как? |
| **¿Por qué?** | Causa o motivo. | *¿**Por qué** no vienes?* | Why? / Почему? |
| **¿Cuánto/a/os/as?** | Cantidad (variable). | *¿**Cuántos** años tienes?* | How many? / Сколько? |
| **¿Cuál / es?** | Selección o identificación. | *¿**Cuál** es tu nombre?* | Which? / What? / Какой? |

---

## 🌓 Diferencias Importantes

### 1. ¿Qué? vs ¿Cuál?
Esta es una de las mayores dudas. Aquí tienes las reglas generales:

- **¿Qué? + Sustantivo**: Se usa para preguntar por la clase de objeto.
  - *¿**Qué** película prefieres?*
- **¿Cuál? + de + Sustantivo**: Se usa para elegir entre un grupo específico.
  - *¿**Cuál de** estas películas prefieres?*
- **¿Qué? + Verbo (Definición)**:
  - *¿**Qué** es la paella?*
- **¿Cuál? + Verbo (Identificación)**:
  - *¿**Cuál** es tu dirección? / ¿**Cuál** es tu favorito?*

### 2. ¿Dónde? vs ¿Adónde? vs ¿De dónde?
Depende del movimiento y el origen:
- **¿Dónde?**: Ubicación estática. (*¿Dónde estás?*)
- **¿Adónde?**: Destino o dirección (verbo de movimiento como *ir*). (*¿Adónde vas?*)
- **¿De dónde?**: Origen o procedencia. (*¿De dónde eres?*)

### 3. ¿Por qué? vs ¿Para qué?
- **¿Por qué?**: Busca la razón o causa. (*¿Por qué estudias? - Porque me gusta.*)
- **¿Para qué?**: Busca la finalidad o el objetivo. (*¿Para qué sirve esto? - Para abrir botellas.*)

---

## 🗣️ Preguntas Frecuentes de Nivel A1-A2

- ¿**Cómo** te llamas?
- ¿**De dónde** eres? (Origen)
- ¿**A qué** te dedicas? (Profesión)
- ¿**Dónde** vives? (Ubicación)
- ¿**Con quién** vives? (Compañía)
- ¿**Cuántos** años tienes? (Edad)
- ¿**Cuándo** es tu cumpleaños? (Fecha)
- ¿**Qué** hora es? (Hispanoamérica: *¿Cuál hora es?*)
- ¿**Cuál** es tu número de teléfono?
