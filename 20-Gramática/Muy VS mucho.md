# ⚖️ Gramática: Muy vs. Mucho

> [!TIP] Regla rápida
> - **Muy** es un adverbio (nunca cambia).
> - **Mucho** puede ser adjetivo (cambia de género/número) o adverbio.

---

## 1. MUY (Adverbio)
Se usa para aumentar la intensidad de un **adjetivo** o un **adverbio**. **Nunca cambia** (siempre es "muy").

**Estructura:** `MUY + Adjetivo/Adverbio`

| Ejemplo | Inglés | Ruso |
| :--- | :--- | :--- |
| El ordenador es **muy** rápido. | The computer is **very** fast. | Компьютер **очень** быстрый. |
| Dénia es **muy** bonita. | Dénia is **very** beautiful. | Дения **очень** красивая. |
| Yo escribo **muy** bien. | I type **very** well. | Я пишу **очень** хорошо. |

---

## 2. MUCHO (Adjetivo o Adverbio)

### A. Como Adjetivo (con Sustantivos)
Acompaña a un nombre y **debe coincidir** en género (masculino/femenino) y número (singular/plural).

**Estructura:** `MUCHO/A/OS/AS + Sustantivo`

| Ejemplo | Inglés | Ruso |
| :--- | :--- | :--- |
| Tengo **mucho** trabajo. | I have **a lot of** work. | У меня **много** работы. |
| Hay **mucha** gente. | There are **many** people. | Там **много** людей. |
| Mi PC tiene **muchos** cables. | My PC has **many** cables. | У моего ПК **много** кабелей. |
| Hay **muchas** ventanas. | There are **many** windows. | Там **много** окон. |

### B. Como Adverbio (con Verbos)
Se usa después de un verbo para indicar cantidad de acción. **No cambia**.

**Estructura:** `Verbo + MUCHO`

| Ejemplo | Inglés | Ruso |
| :--- | :--- | :--- |
| Yo estudio **mucho**. | I study **a lot**. | Я **много** учусь. |
| El escáner trabaja **mucho**. | The scanner works **a lot**. | Сканер **много** работает. |

---

## ⚠️ Las 4 Excepciones Importantes
**No** decimos "muy mejor" o "muy mayor". Usamos **MUCHO** delante de estas 4 palabras comparativas:

1. **Mucho mejor** (Much better / Гораздо лучше)
2. **Mucho peor** (Much worse / Гораздо хуже)
3. **Mucho mayor** (Much older / Гораздо старше)
4. **Mucho menor** (Much younger / Гораздо младше)

---

## ✍️ Ejemplos de Práctica (A2)

1. Mi ratón es **muy** pequeño. 
   *(My mouse is very small / Моя мышь очень маленькая)*
2. En Dénia hay **mucha** luz. 
   *(In Dénia there is a lot of light / В Дении много света)*
3. El teclado es **muy** caro, pero es **mucho** mejor que el viejo. 
   *(The keyboard is very expensive, but it's much better than the old one)*
4. Hoy no tengo **mucho** tiempo para estudiar. 
   *(Today I don't have much time to study / Сегодня у меня нет много времени на учебу)*
