# Ampliación: Otras Palabras Negativas (Nunca, Ningún, Nadie...)

En español, estas palabras siguen la **regla de la doble negación**: si van después del verbo, el verbo debe llevar un **NO** delante.

---

### 1. ⏳ Frecuencia: NUNCA / JAMÁS
Ambas significan lo mismo (*never*), pero "jamás" es más fuerte o enfático.

* **Estructura A:** `NUNCA` + `VERBO`
  * *Ejemplo:* "**Nunca** bebo café por la noche."
* **Estructura B:** `NO` + `VERBO` + `NUNCA`
  * *Ejemplo:* "**No** bebo café **nunca** por la noche."

---

### 2. 👤 Personas y Cosas: NADIE / NADA
* **Nadie** (*nobody*): Se refiere exclusivamente a personas.
* **Nada** (*nothing*): Se refiere exclusivamente a objetos o conceptos.

> [!EXAMPLE] Ejemplos
> * "**Nadie** sabe dónde está la llave." / "**No** hay **nadie** en la playa."
> * "**Nada** es imposible." / "**No** quiero comer **nada** ahora."

---

### 3. 📦 Cantidad: NINGÚN / NINGUNO / NINGUNA
Equivale a *none* o *not any*. ¡Ojo con el cambio de forma!

* **Ningún:** Se usa solo delante de sustantivos **masculinos**.
  * *Ejemplo:* "No tengo **ningún** libro de cocina."
* **Ninguno:** Se usa cuando **no** mencionamos el sustantivo (pronombre).
  * *Ejemplo:* "¿Tienes libros? No, no tengo **ninguno**."
* **Ninguna:** Se usa para femenino (tanto delante del nombre como solo).
  * *Ejemplo:* "No hay **ninguna** farmacia abierta." / "No tengo **ninguna**."

---

### 🔄 Tabla de Opuestos (Positivo vs. Negativo)

| Afirmativo | Negativo |
| :--- | :--- |
| **Alguien** (somebody) | **Nadie** (nobody) |
| **Algo** (something) | **Nada** (nothing) |
| **Algún / Alguno** (some) | **Ningún / Ninguno** (none) |
| **Siempre** (always) | **Nunca / Jamás** (never) |
| **También** (also) | **Tampoco** (neither) |

---

### 💡 Reglas de Oro para tu Obsidian

> [!IMPORTANT] La Doble Negación
> En español es obligatorio usar dos negativos si el primero no está al principio:
> * ✅ **No** he visto a **nadie**.
> * ❌ *He visto a nadie* (Incorrecto).

> [!TIP] Tampoco
> Recuerda usar **tampoco** cuando estás de acuerdo con una frase negativa.
> * A: "No me gusta el frío."
> * B: "A mí **tampoco**." (A mí *también no* es un error común).

---
