# 🔄 Pronombres en 3.ª persona: SE vs. LE / LES

## 📌 Diferencia fundamental

- **SE (reflexivo / recíproco):** la acción vuelve al propio sujeto (*a sí mismo / самому себе*) o es mutua entre varias personas (*el uno al otro / друг другу*).
- **LE / LES (objeto indirecto):** la acción se dirige a otra persona (*a él, a ella, a ellos, a ustedes / ему, ей, им, вам*).

Ver también: [[Verbos Reflexivos y Recíprocos]] · [[Verbos como Gustar (Encantar, Doler, etc.)]]

## 📊 Tabla comparativa de verbos frecuentes

| Verbo | Con **SE** *(reflexivo / recíproco)* | Con **LE / LES** *(objeto indirecto)* |
| :--- | :--- | :--- |
| **lavar** | **Él se lava.** *(He washes himself. / Он моется.)* | **Él le lava las manos.** *(He washes his/her hands. / Он моет ему/ей руки.)* |
| **poner** | **Ellos se ponen el casco.** *(They put on their helmets. / Они надевают шлемы.)* | **Ellos les ponen el casco.** *(They put helmets on them. / Они надевают им шлемы.)* |
| **hablar** | **Ellos se hablan.** *(They talk to each other. / Они разговаривают друг с другом.)* | **Ellos les hablan.** *(They talk to them. / Они разговаривают с ними.)* |
| **escribir** | **Ellos se escriben.** *(They write to each other. / Они переписываются.)* | **Ellos les escriben.** *(They write to them. / Они пишут им.)* |
| **comprar** | **Él se compra una casa.** *(He buys himself a house. / Он покупает себе дом.)* | **Él le compra una casa.** *(He buys him/her a house. / Он покупает ему/ей дом.)* |
| **cortar** | **Él se corta.** *(He cuts himself. / Он порезался.)* | **Él le corta el pelo.** *(He cuts his/her hair. / Он стрижёт ему/ей волосы.)* |
| **dar** | **Él se da cuenta.** *(He realizes (pronominal verb). / Он понимает, замечает.)* | **Él le da un regalo.** *(He gives him/her a gift. / Он даёт ему/ей подарок.)* |

## 💡 Ejemplos de contraste directo

1. **Reflexivo vs. indirecto (singular):**
   - *Juan **se** limpia las botas.* (*Juan cleans his own boots.* / Хуан чистит себе ботинки.)
   - *Juan **le** limpia las botas a su padre.* (*Juan cleans his father's boots.* / Хуан чистит ботинки своему отцу.)
2. **Recíproco vs. indirecto (plural):**
   - *Mis amigos **se** ayudan mucho.* (*My friends help each other a lot.* / Мои друзья очень помогают друг другу.)
   - *Mis amigos **les** ayudan con la mudanza.* (*My friends help them with the move.* / Мои друзья помогают им с переездом.)
