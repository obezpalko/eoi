# 🔣 Signos de puntuación y símbolos en español

## 📌 Símbolos especiales y de teclado

| Símbolo | Nombre en español | Uso / Notas |
| :---: | :--- | :--- |
| **@** | Arroba | *En correos electrónicos y redes sociales.* |
| **&** | Ampersand / Et / "Y" comercial | *Poco usado en texto normal en español.* |
| **\*** | Asterisco | *Para notas al pie o llamadas de atención.* |
| **#** | Almohadilla / Numeral / Hashtag | *Almohadilla (España), numeral (Latam).* |
| **%** | Por ciento / Porcentaje | *Se lee "por ciento".* |
| **_** | Guion bajo | *Muy común en informática y correos.* |
| **-** | Guion / Guion medio | *Para unir palabras o separar sílabas.* |
| **–** | En dash / Guion medio | *Para rangos (ej. 10–12).* |
| **—** | Raya / Guion largo | *Para diálogos o incisos.* |
| **/** | Barra / Barra diagonal | *En rutas de archivos y fechas.* |
| **\\** | Barra invertida / Contra-barra | *Muy usado en informática (Windows/Linux).* |
| **\|** | Barra vertical / Tubería (Pipe) | *Usado en programación.* |
| **~** | Virgulilla | *El símbolo sobre la letra Ñ o la tilde de la eñe.* |

## ✍️ Signos de puntuación principales

| Signo | Nombre en español | Ejemplos / Notas |
| :---: | :--- | :--- |
| **.** | Punto | *Punto y seguido, punto y aparte, punto final.* |
| **,** | Coma | *Separa elementos en una lista o incisos.* |
| **;** | Punto y coma | *Pausa intermedia entre el punto y la coma.* |
| **:** | Dos puntos | *Para enumeraciones o citas.* |
| **...** | Puntos suspensivos | *Siempre son exactamente tres puntos.* |
| **¿ ?** | Signos de interrogación | *Apertura (**¿**) y cierre (**?**).* |
| **¡ !** | Signos de exclamación / admiración | *Apertura (**¡**) y cierre (**!**).* |

## 📐 Paréntesis, corchetes y comillas

|  Signo  | Nombre en español                        | Notas                                          |
| :-----: | :--------------------------------------- | :--------------------------------------------- |
| **( )** | Paréntesis                               | *Paréntesis de apertura y de cierre.*          |
| **[ ]** | Corchetes                                | *Usados en notas, citas y matemáticas.*        |
| **{ }** | Llaves                                   | *Apertura y cierre de llaves.*                 |
| **« »** | Comillas latinas / angulares / españolas | *Las preferidas en textos impresos y libros.*  |
| **“ ”** | Comillas dobles / inglesas               | *Las más comunes en teclado.*                  |
| **‘ ’** | Comillas simples                         | *Para citas dentro de citas.*                  |
| **< >** | Signos de menor que / mayor que          | *O comillas simples angulares en informática.* |
