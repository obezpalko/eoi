# ⚖️ Obligación Impersonal: HAY QUE + Infinitivo

A diferencia de "Tener que", el verbo **Hay que** no se conjuga. Siempre se usa la misma forma para todo el mundo.

---

## 🔘 HAY QUE + Infinitivo
**General / Impersonal / Universal**
* **English:** "It is necessary to" / "One must" / "You have to" (in general).
* **Русский:** **Нужно / Надо / Необходимо** (в общем, для всех).
* **Uso:** Reglas generales, instrucciones o necesidades que se aplican a cualquier persona. No tiene sujeto (no es para "yo" o "tú", es para "todos").

| Ejemplo en Español | English Translation | Перевод на русский |
| :--- | :--- | :--- |
| **Hay que** comer sano. | One must eat healthy. | **Нужно** есть здоровую пищу. |
| **Hay que** pagar impuestos. | It is necessary to pay taxes. | **Нужно** платить налоги. |
| **Hay que** estudiar para aprender. | You have to study to learn. | **Надо** учиться, чтобы научиться. |

---

## 🔄 Comparativa: Personal vs. Impersonal

| Estructura | Tipo | Sujeto | Ejemplo |
| :--- | :--- | :--- | :--- |
| **Tener que** | Personal | Yo, Tú, Él... | **Tienes que** (tú) comprar leche. |
| **Hay que** | Impersonal | Nadie en concreto | **Hay que** comprar leche (está vacía la nevera). |

## 📊 Tabla Completa de Obligación (A2)

| Verbo | Fuerza | Traducción (EN) | Traducción (RU) | Enfoque |
| :--- | :--- | :--- | :--- | :--- |
| **Tener que** | 🔴 Alta | Have to | Должен | Persona específica |
| **Hay que** | 🔴 Alta | One must | Нужно / Надо | Regla general |
| **Deber** | 🟡 Media | Should | Следует | Consejo / Ética |
| **Poder** | 🟢 Baja | Can / May | Можно / Могу | Permiso / Opción |

---

## 📝 Ejemplos en contexto (Alex en Dénia)

1. **Instrucción general:** "Para ir al Castillo, **hay que** (one must) subir una cuesta."
2. **Obligación personal:** "Alex, **tienes que** (you have to) renovar tu tarjeta de residencia."
3. **Consejo moral:** "No se **debe** (shouldn't) tirar basura en el Montgó."
4. **Posibilidad:** "En el puerto **puedes** (can) comprar pescado fresco."

---

> [!IMPORTANT] **La diferencia clave**
> * Si dices "**Tengo que** trabajar", hablas de TI.
> * Si dices "**Hay que** trabajar", hablas de una verdad universal para la sociedad.
