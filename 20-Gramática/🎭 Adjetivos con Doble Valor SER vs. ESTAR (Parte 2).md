# 🎭 Adjetivos con Doble Valor: SER vs. ESTAR (Parte 2)

Más ejemplos de cómo el verbo cambia el significado del adjetivo. / More examples of how the verb changes the meaning. / Еще примеры того, как глагол меняет значение прилагательного.

---

| Adjetivo | 🔵 SER (Character / Essence) | 🟢 ESTAR (State / Result) |
| :--- | :--- | :--- |
| **1. Abierto** | **Es abierto:** Extroverted/Open-minded. / Общительный. | **Está abierto:** It is open (door/shop). / Открыто. |
| **2. Cerrado** | **Es cerrado:** Introverted/Shy. / Замкнутый. | **Está cerrado:** It is closed (door/shop). / Закрыто. |
| **3. Delicado** | **Es delicado:** Fragile/Fine. / Хрупкий/Изящный. | **Está delicado:** Weak health. / В слабом состоянии (здоровье). |
| **4. Atento** | **Es atento:** Courteous/Polite. / Внимательный (вежливый). | **Está atento:** Paying attention. / Внимательный (слушает сейчас). |
| **5. Fresco** | **Es fresco:** New/Recent. / Свежий (новый). | **Está fresco:** It is cool (weather) / Cheeky. / Прохладно. |
| **6. Pesado** | **Es pesado:** Boring/Annoying person. / Нудный/Тяжелый человек. | **Está pesado:** It weighs a lot (object). / Тяжелый (о весе предмета). |
| **7. Limpio** | **Es limpio:** A clean person (habit). / Чистоплотный человек. | **Está limpio:** It is clean (now). / Чисто (после уборки). |
| **8. Católico** | **Es católico:** Religion. / Католик. | **No está católico:** Not feeling well (idiom). / Неважно себя чувствует. |
| **9. Interesado** | **Es interesado:** Selfish/Materialistic. / Корыстный. | **Está interesado:** Interested in something. / Заинтересован. |
| **10. Maduro** | **Es maduro:** Mature person. / Зрелый человек. | **Está maduro:** Ripe fruit. / Спелый фрукт. |

## 📝 Ejemplos en contexto para Alex

1. **Personalidad vs. Puertas:**
   - "Mi vecino en Dénia **es** muy **abierto**" (He is very friendly/social).
   - "El supermercado ya **está abierto**" (The shop is open).

2. **Gente aburrida vs. Objetos:**
   - "Ese hombre **es** un **pesado**, siempre habla de lo mismo" (He is annoying/boring).
   - "Esta maleta **está** muy **pesada**, ¿qué llevas dentro?" (It weighs a lot).

3. **Fruta en el mercado:**
   - "Juan **es** un chico muy **maduro** para su edad" (He is a mature guy).
   - "Este aguacate ya **está maduro**, podemos comerlo" (The avocado is ripe).

4. **Higiene:**
   - "Yo **soy** una persona **limpia**" (I am a clean person by habit).
   - "Mi coche **está limpio** porque lo lavé ayer" (The car is clean right now).

## 💡 Truco para recordar (Memory Trick)



* **¿Quién es?** → Usa **SER**.
* **¿Cómo está?** → Usa **ESTAR**.

> [!WARNING] **Dato curioso**
> En España, si alguien dice "**No estoy muy católico**", no habla de religión. Significa que **no se siente bien de salud** o que tiene mal cuerpo (por ejemplo, después de un carajillo de más).
