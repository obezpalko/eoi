# Adverbios y Preposiciones

- **abajo** - down, below / внизу
- **al final** - at the end / в конце
- **además** - also, besides / кроме того
- **adelante** - forward, ahead / вперед
- **ahí** - there (near) / там (рядом)
- **allí** - there (far) / там (далеко)
- **antes** - before / раньше, перед
- **delante de** - in front of / перед (чем-то)
- **detrás de** - behind / позади
- **aquí** - here / здесь
- **arriba** - up, above / вверху, наверху
- **enfrente** - opposite, across / напротив
- **bastante** - quite, enough / довольно, достаточно
- **bien** - well / хорошо
- **cerca** - near / близко
- **despacio** - slowly / медленно
- **después** - after / после
- **jamás** - never / никогда (усиленно)
- **lejos** - far / далеко
- **mal** - badly / плохо
- **nunca** - never / никогда
- **siempre** - always / siempre
