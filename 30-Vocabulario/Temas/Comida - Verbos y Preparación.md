# Comida - Verbos y Preparación

## Verbos Principales
- **almorzar** (o->ue) - to have lunch / обедать
- **cenar** - to have dinner / ужинать
- **comer** - to eat / есть
- **desayunar** - to have breakfast / завтракать
- **merendar** (e->ie) - to have a snack / полдничать
- **tapear** - to go for tapas / ходить по тапас-барам

## Acciones de Cocina
- **cocinar** - to cook (general/technical) / готовить (технически)
- **hacer** - to do/make (common for daily meals) / делать (еду)
- **preparar** - to prepare (includes organization/cold dishes) / подготавливать
- **borrar** - to erase (e.g. from a menu) / стирать
- **cortar** - to cut / резать
- **freír** (e->i) - to fry / жарить
- **repasar** - to review / повторять (рецепт)
- **sustituir** - to replace / заменять (ингредиент)

### Diferencia entre Cocinar, Preparar y Hacer
- **Cocinar**: Aplicar calor o elaborar platos complejos.
- **Preparar**: Proceso completo (cortar, mezclar, poner la mesa). Común para platos fríos.
- **Hacer**: El más frecuente para las comidas principales (desayuno, comida, cena).

## Estados de la Comida
- **borracho/a** - drunk / пьяный
- **goloso/a** - sweet-toothed / сладкоежка
- **maduro/a** - ripe / спелый
- **picante** - spicy / острый
- **rico/a** - tasty, delicious / вкусный
- **salado/a** - salty / соленый
- **soso/a** - bland / пресный
