# 💻 Vocabulario Completo: El Ordenador e Informática

> [!INFO] Gramática: Hay vs. Tener
> - **Hay** (There is/are | Есть/Имеется): Para existencia general. 
>   *Ejemplo: Hay un cable aquí.*
> - **Tener** (To have | Иметь): Для описания частей устройства. 
>   *Ejemplo: El ordenador tiene un teclado.*

## 🖱️ Verbos y Acciones (Глаголы и действия)

- **Encender**: To turn on | Включить.
- **Apagar**: To turn off | Выключить.
- **Reiniciar**: To restart | Перезагрузить.
- **Guardar**: To save | Сохранить.
- **Borrar**: To delete | Удалить.
- **Escribir**: To type | Печатать.
- **Hacer clic**: To click | Кликнуть.
- **Descargar**: To download | Скачать.
- **Subir**: To upload | Загрузить (в сеть).

## ✍️ Ejemplos de Práctica (Примеры предложений)

1. **En mi mesa hay una pantalla grande y dos altavoces.**
   *(On my desk there is a large screen and two speakers / На моем столе есть большой экран и две колонки.)*

2. **Mi ordenador portátil tiene un teclado español.**
   *(My laptop has a Spanish keyboard / У моего ноутбука испанская клавиатура.)*

3. **¿Hay un escáner en la oficina?**
   *(Is there a scanner in the office? / В офисе есть сканер?)*

4. **Necesito una alfombrilla nueva para el ratón.**
   *(I need a new mouse pad / Мне нужен новый коврик для мыши.)*

5. **Tengo que guardar el documento antes de apagar el ordenador.**
   *(I have to save the document before turning off the computer / Мне нужно сохранить документ перед выключением компьютера.)*

6. **El ordenador va muy lento y necesito reiniciar el sistema.**
   *(The computer is running very slowly and I need to restart the system / Компьютер работает очень медленно, мне нужно перезагрузить систему.)*
