# Las Herramientas

Herramientas comunes para el bricolaje y las reparaciones en casa. Vistas en la [[../../11-Lecciones-2A2/20261005 Lección tres|lección 003 (2A2)]].
*Ejemplo: Necesito **un destornillador** para cambiar las pilas.*

## 1. Para cortar, golpear y perforar

| Palabra | Traducción (EN/RU) | Ejemplo de uso |
| :--- | :--- | :--- |
| **El martillo** | Hammer / Молоток | Clavo un cuadro con el martillo. |
| **La sierra** | Saw / Пила | Corto la madera con una sierra. |
| **El serrucho** | Hand saw / Ножовка | El serrucho es una sierra de mano. |
| **El taladro** | Drill / Дрель | Hago un agujero en la pared con el taladro. |
| **La broca** | Drill bit / Сверло | Pongo una broca nueva en el taladro. |
| **El formón** | Chisel / Стамеска | Trabajo la madera con un formón. |
| **El cúter** | Utility knife / Канцелярский нож | Abro la caja con el cúter. |

## 2. Para apretar y sujetar

| Palabra | Traducción (EN/RU) | Ejemplo de uso |
| :--- | :--- | :--- |
| **El destornillador** | Screwdriver / Отвёртка | Aprieto el tornillo con el destornillador. |
| **Los alicates** | Pliers / Плоскогубцы | Corto el cable con los alicates. |
| **La llave inglesa** | Adjustable wrench / Разводной ключ | Aprieto la tuerca con la llave inglesa. |
| **El tornillo de banco** | Vise / Тиски | Sujeto la pieza en el tornillo de banco. |

## 3. Para medir y terminar

| Palabra | Traducción (EN/RU) | Ejemplo de uso |
| :--- | :--- | :--- |
| **El metro / La cinta métrica** | Tape measure / Рулетка | Mido la mesa con el metro. |
| **El nivel** | Spirit level / Строительный уровень | Uso el nivel para colgar la estantería recta. |
| **El papel de lija** | Sandpaper / Наждачная бумага | Lijo la puerta con papel de lija. |
| **El cepillo de carpintero** | Hand plane / Рубанок | Alisa la madera con el cepillo de carpintero. |
| **La cinta aislante** | Electrical tape / Изолента | Cubro el cable con cinta aislante. |

## 4. Piezas pequeñas

| Palabra | Traducción (EN/RU) | Ejemplo de uso |
| :--- | :--- | :--- |
| **Los clavos** | Nails / Гвозди | Necesito clavos para colgar el cuadro. |
| **Los tornillos** | Screws / Винты, шурупы | Los tornillos están en la caja. |
| **Las tuercas** | Nuts / Гайки | Cada tornillo lleva una tuerca. |
| **Las arandelas** | Washers / Шайбы | Pon una arandela debajo de la tuerca. |
