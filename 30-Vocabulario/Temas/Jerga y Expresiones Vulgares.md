# Jerga y Expresiones Vulgares

Este documento contiene términos coloquiales, jerga y palabras malsonantes (palabrotas) que son comunes en el español hablado, especialmente en España. Es importante conocerlas para entender conversaciones naturales, aunque deben usarse con precaución.

## 1. Expresiones con "Cojones"
En España, la palabra "cojones" (testículos) es extremadamente versátil y se usa para expresar multitud de estados de ánimo.

| Expresión                   | Significado / Uso                          | Ejemplo                                     |
| :-------------------------- | :----------------------------------------- | :------------------------------------------ |
| **¡Cojones!**               | Exclamación de sorpresa, enfado o énfasis. | *¡Cojones, qué frío hace!*                  |
| **Tener cojones**           | Ser valiente o tener coraje.               | *Hay que tener cojones para hacer eso.*     |
| **Estar hasta los cojones** | Estar muy harto o cansado de algo/alguien. | *Estoy hasta los cojones de este tráfico.*  |
| **Por cojones**             | Por obligación o por fuerza.               | *Lo vas a hacer por cojones.*               |
| **No tener cojones**        | Ser cobarde.                               | *No tienes cojones de decírselo a la cara.* |

## 2. Confusiones Peligrosas (Phonetic Similarities)
Hay palabras que suenan muy parecido pero tienen significados radicalmente distintos. Una confusión aquí puede ser embarazosa o divertida.

| Palabra     | Significado (ES)      | Traducción (RU)        | Nota                                                     |
| :---------- | :-------------------- | :--------------------- | :------------------------------------------------------- |
| **Cajón**   | Drawer                | Ящик (мебели)          |                                                          |
| **Cojín**   | Cushion               | Подушка (декоративная) |                                                          |
| **Cojones** | Vulgarism (testicles) | Яйца (вульг.)          | ¡Cuidado con la pronunciación!                           |
| **Conejo**  | Rabbit                | Кролик                 | También puede tener sentido vulgar en algunos contextos. |

## 3. Sustantivos Coloquiales y Jerga
Sustantivos que tienen un significado informal o que se usan comúnmente en la calle.

| Palabra               | Significado Coloquial                             | Traducción (RU)    | Ejemplo                                            |
| :-------------------- | :------------------------------------------------ | :----------------- | :------------------------------------------------- |
| **La jeta**           | Face / Snout / Cheek (impudence)                  | Морда / Наглость   | *¡Qué jeta tienes!* (You have some nerve!)         |
| **La jarana**         | Partying / Revelry                                | Кутеж / Веселье    | *Nos fuimos de jarana toda la noche.*              |
| **El pedo**           | Fart / Being drunk (slang)                        | Пук / Пьянка       | *Lleva un pedo impresionante.* (He is very drunk). |
| **Harto/a**         | Fed up / Sick of something                        | Сыт по горло       | *Estoy harto de tus mentiras.*                    |
| **La resaca**         | Hangover                                          | Похмелье           | *Tengo una resaca horrible.*                       |
| **La yaya / El yayo** | Grandma / Grandpa                                 | Бабуля / Дедуля    | *Voy a ver a mi yaya este domingo.*                |
| **Gordo/a**           | Fat (can be very offensive)                       | Толстый            | *Use "gordito/a" or "rellenito/a" to be polite.*   |
| **Guiri**             | Foreign tourist (usually North European/American) | Иностранный турист | *Esa playa está llena de guiris.*                  |
| **Flus-flus / Espray / Fu-fu** | Spray / Atomizer (Onomatopoeia) | Пшик-пшик / Спрей | *Ponte un poco de flus-flus (colonia).* |

## 4. Otras expresiones comunes
- **A fuego / Afuego**: Cool, great, "on fire" / "Круто", "огонь".
- **A huevo**: Muy fácil / "На блюдечке".
- **De puta madre**: Muy bien, excelente (vulgar pero muy común) / "Офигенно".
- **Joder**: Exclamación multiuso (sorpresa, enfado, dolor) / "Блин", "Черт".
