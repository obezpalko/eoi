# El Verbo Estar (To be)

| Pronombre           | Conjugación | Ejemplo                   |
| ------------------- | ----------- | ------------------------- |
| Yo                  | estoy       | Yo estoy en casa          |
| Tú                  | estás       | Tú estás cansado          |
| Él/Ella/Usted       | está        | Él está en el trabajo     |
| Nosotros/as         | estamos     | Nosotros estamos felices  |
| Vosotros/as         | estáis      | Vosotros estáis en Madrid |
| Ellos/Ellas/Ustedes | están       | Ellos están estudiando    |

**Usos principales (PLACE):**

- **P**osición: El libro está sobre la mesa.
- **L**ugar/Localización: Estamos en la escuela.
- **A**cción (con gerundio): Estoy hablando.
- **C**ondición (estados temporales): Ella está enferma.
- **E**moción: Están muy contentos.

## [[ser]] vs. Estar

| Ser (Permanencia/Esencia) | Estar (Temporalidad/Estado) |
| :--- | :--- |
| **D**escripción (Soy alto) | **P**osición (Está de pie) |
| **O**cupación (Somos médicos) | **L**ugar (Estoy en París) |
| **C**aracterísticas (Es inteligente) | **A**cción (Estamos comiendo) |
| **T**iempo (Son las tres) | **C**ondición (Estás cansado) |
| **O**rigen (Son de Italia) | **E**moción (Está triste) |
| **R**elación (Él es mi padre) | |

**Diferencias clave:**
- **Ser** se usa para cualidades inherentes, identidad y tiempo.
- **Estar** se usa para estados temporales, ubicaciones y acciones en curso.
