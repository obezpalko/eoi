# El Verbo Ser (To be)

| Pronombre | Conjugación | Ejemplo |
|-----------|-------------|---------|
| Yo | soy | Yo soy ingeniero |
| Tú | eres | Tú eres de España |
| Él/Ella/Usted | es | Ella es profesora |
| Nosotros/as | somos | Nosotros somos estudiantes |
| Vosotros/as | sois | Vosotros sois amigos |
| Ellos/Ellas/Ustedes | son | Ellos son médicos |

**Usos principales (DOCTOR):**

- **D**escripción: Yo soy alto y delgado.
- **O**cupación: Ella es profesora de español.
- **C**aracterísticas: El perro es muy inteligente.
- **T**iempo: Hoy es lunes. / Son las cinco de la tarde.
- **O**rigen: Nosotros somos de Argentina.
- **R**elación: Ellos son mis hermanos.

## Ser vs. Estar

| Ser (Permanencia/Esencia) | Estar (Temporalidad/Estado) |
| :--- | :--- |
| **D**escripción (Soy alto) | **P**osición (Está de pie) |
| **O**cupación (Somos médicos) | **L**ugar (Estoy en París) |
| **C**aracterísticas (Es inteligente) | **A**cción (Estamos comiendo) |
| **T**iempo (Son las tres) | **C**ondición (Estás cansado) |
| **O**rigen (Son de Italia) | **E**moción (Está triste) |
| **R**elación (Él es mi padre) | |

**Diferencias clave:**
- **Ser** se usa para cualidades inherentes, identidad y tiempo.
- **Estar** se usa para estados temporales, ubicaciones y acciones en curso.
